## AI Use

Folder front door. These tables add **variety, texture, and pacing** during travel, downtime, and city scenes without requiring new content generation. Every table result routes back to **existing authored content** (encounter tables, hooks, rumors, factions, clocks) — tables produce situations, not noise. Built 2026-07-07 (closes the long-standing "populate /15_random_tables/" gap).

**Division of labor:** *combat/creature* encounters live in `../13_encounters_and_bestiary/` (regional tables, `TRAVEL_ENCOUNTERS.md`); *treasure* lives in `../14_treasure_and_artifacts/`; *authored hooks/rumors* live in `../09_quests/`. This folder holds the connective-tissue tables: events, weather, urban color, quick NPC traits, and rumor-surfacing logic.

## Files

| File | Use when |
|---|---|
| `TRAVEL_EVENTS.md` | The player travels overland/by water and you want a non-combat event or complication |
| `WEATHER.md` | Any scene needs weather; travel legs; season turns (campaign starts Greyfall, mid-autumn) |
| `URBAN_EVENTS.md` | Street color, downtime days, or a living-city beat in any settlement |
| `NPC_PERSONALITY.md` | You must improvise a minor NPC on the spot (then record them per protocol) |
| `RUMOR_SURFACES.md` | Deciding *which* authored rumor/hook surfaces, where, and from whom |

## Rules Of Use

- Roll **once** per travel leg / downtime day / street scene — these season play, they don't replace it.
- A result that contradicts the current fiction: shift one row or skip. Never force a table result.
- Any event that becomes important gets recorded per `../16_ai_session_packs/SESSION_END_UPDATE_CHECKLIST.md`.
- Creature references follow the bestiary's verified two-track rule (`../13_encounters_and_bestiary/CREATURE_SOURCE_REFERENCE.md`) — tables here point to those files rather than naming new monsters.
