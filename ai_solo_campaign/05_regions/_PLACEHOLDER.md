# _PLACEHOLDER.md — /05_regions/

## Purpose

This folder will contain one file per region in the campaign world.

## Current Status

**Populated.** This folder contains the campaign's region files: `SUNDERING_REACH.md` (starting region), `ASHGARDEN_VALE.md`, `TOLLWOOD.md`, and `PALE_COAST.md` (Ring 1), plus a `wilderness/` subfolder of wilderness-site files. The full continent of Orrun (5 built + 13 placeholder far regions) is defined in `../04_world_atlas/`. For how to load regional content during play, see `../00_control/RETRIEVAL_GUIDE.md` ("Entering a region").

## Expected Contents

Each region file should follow the Region Standard defined in `00_control/WORLDBUILDING_STANDARDS.md`:

- One-sentence identity
- Player-facing overview
- DM-only truth
- Geography
- Major and minor settlements
- Wilderness zones
- Travel routes
- Factions present
- Regional conflicts
- Regional secrets
- Recurring threats
- Quest hooks
- What changes if ignored

## File Naming Convention

`[region-name].md` — e.g., `ashfield-lowlands.md`, `the-grey-reach.md`

## Stage 1 Target

The starting region identity will be established during Stage 1. Full regional development happens in Stage 3.
