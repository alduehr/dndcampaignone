# _PLACEHOLDER.md — /07_factions/major_factions/

## Purpose

This folder will contain one file per major faction in the campaign world.

## Current Status

**Populated.** This folder contains files for all seven major factions: `ASHEN_WARDENS.md`, `CINDER_LEDGER.md`, `MOURNERS_CIRCLE.md`, `REACHWARD_COMPACT.md`, `GRAVECALLERS.md`, `CONCORD_REMNANT.md`, and `HOLLOW_COURT.md` (DM-only apex faction — never surface). Each is operational (clocks, quest chains, combat capability). See `../FACTION_INDEX.md`, `../FACTION_RELATIONSHIP_MAP.md`, and `../FACTION_TURN_RULES.md`.

## Expected Contents

Each major faction file should follow the Faction File Standard defined in `00_control/FACTION_STANDARDS.md`:

- One-sentence identity
- Public face
- True agenda (DM-only)
- Founding / history
- Leader
- Important members
- Resources
- Methods
- Territory / influence
- Internal conflict
- Allies and enemies
- Secrets
- Current activity
- Escalation clock
- Quests offered and quests against
- How they react to the player
- What they do if ignored
- Solo-player safety considerations

## File Naming Convention

`[faction-name].md` — e.g., `the-iron-compact.md`, `order-of-the-pale-flame.md`
