## AI Use

Index of every adventure site whose core challenge is a **puzzle, investigation, social-infiltration, or environmental problem** rather than combat — and a reference for each site's puzzle type, DCs, intended and alternate solutions, failure consequence, costly bypass, and clue dependency. Use this to run non-combat dungeons fairly and per `MYSTERY_STANDARDS.md`: **present puzzles, do not solve them; accept any clever valid solution; never gate story progress behind one failed roll.** Most Stage 12 sites are puzzle/investigation-weighted by design — the campaign's dungeons are not combat gauntlets.

## Design Rules (all puzzle sites)

- **Three-path minimum:** every important locked conclusion has at least three ways through (read it / find a key / clever alternate, or social / stealth / faction).
- **Fair failure:** failure costs time, attention, a clock-tick, a complication — not a dead end or a cheap death.
- **Costly bypass always exists:** coin, a favor, a faction debt, or a louder/riskier route.
- **Accept clever solutions:** if the player proposes a valid in-fiction answer, take it over the "intended" one.
- **Language gates are learnable:** Concord Script is the recurring gate; it is gained via Remnant scholars, named NPCs, *Comprehend Languages*, or a found primer — never a permanent wall.

## Puzzle Type Glossary

| Type | Description | Recurring gate |
|---|---|---|
| Script / Translation | Read Concord Script (or Old Custodial, late) to learn or unlock | Concord Script (`LANGUAGES.md`) |
| Lock-Glyph / Watchword | A Concord star-sequence seal or a guardian's challenge-response | Script, a key, or star-lore |
| Navigation | Read terrain/markers/the dead's drift to find the safe path | Survival; a guide |
| Tide / Cycle | Time a flooding or rising-water/lava cycle | Survival; a tide-table |
| Social Infiltration | Talk/turn/pose your way past living foes; lift a ledger | Persuasion/Insight/Deception; a contact |
| Environmental Survival | Manage heat/gas/cold/sinking to survive the site itself | Prep/gear; a guide |
| Ritual / Closing-Word | Lay the dead or quiet a node by rite | Religion; faction aid |
| Choice / Moral | The "boss" is a fork, not a fight | (player judgment) |

## Recurring Puzzle: The Concord Script Gate

The campaign's signature puzzle gate. **It is learnable and never a permanent wall.** Ways through, in rough order of accessibility:

1. *Comprehend Languages* / similar magic (immediate, partial).
2. A reader NPC present (Briss, Tamsin Orr, Oneth Vael, a Remnant scholar, Quorrin Vane).
3. A found primer/rubbing (the Whispering Cairn teaches it; rubbings are portable).
4. The player learns it themselves over downtime (a meaningful progression beat).
5. A costly bypass: buy a translation from the Hush, or pay a scholar.

Late-arc, **Old Custodial** is a second, rarer gate (the inner Custodians' tongue) — relevant only at the endgame.
